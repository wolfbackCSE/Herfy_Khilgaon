# Herfy Menu — Interactive Website

A single-page animated menu website for Herfy Bangladesh, featuring:
- Scroll-driven "burger build" hero animation
- Poster-style clickable food cards with detail modals
- Horizontally-scrolling Mocktails carousel
- Fully responsive layout, no external dependencies (all images embedded)

Developed by **Md Farhadul Islam**.

## Usage
This is a single self-contained `index.html` file — just open it in a browser,
or deploy it as-is on GitHub Pages (enable Pages on the `main` branch, root folder).
